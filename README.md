# WTA Player Rankings (2014–2023): Data Wrangling & EDA in Python

This project explores Women’s Tennis Association (WTA) player rankings from 2014 to 2023.  
It focuses on combining multi-year files into a tidy dataset and performing exploratory analysis 
to highlight ranking distributions and player trend dynamics.

## 📊 Dataset
- **Source:** Public WTA rankings data (2014–2023)
- **Scope:** Player rankings across multiple seasons (multi-file import → single tidy table)

## 🔧 Methods
- Data wrangling with pandas (reading multiple yearly files, concatenation, type fixes)
- Exploratory Data Analysis (summary stats, distributions)
- Trend visualization of rankings over time (matplotlib / seaborn)
- Focused look at top players’ ranking trajectories

## 💡 Key Insights
- A unified dataset across 2014–2023 enables consistent cross-year comparisons
- Visualizations reveal ranking churn dynamics and periods of rapid movement
- Trend views make it easy to spot sustained high performance vs. inconsistency

## 🚀 Skills Demonstrated
- Python data cleaning & reshaping (pandas)
- Visualization (matplotlib, seaborn)
- Working with multi-year data and reproducible notebooks
